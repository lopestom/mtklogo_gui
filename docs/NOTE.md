# Some thoughts for the future of the project - it is completely open source.

## Introduction

Since I put this project on GitHub, it has motivated me to update it and to have more up-to-date options, knowing the capability of the mtklogo source code — always relating it to the use and functionality of the LogoBuilder_v1.6 application, which no one has managed to make anything similar to or that worked 87% as well as it.

Some GitHub users made forks, changed mainly the `mtklogo.yaml` file, used the idea of `mtklogos.sh`, and only @cyberknight777 made improvements to the mtklogo source code. Through that act, my motivation and desire were to bring the project to 95% to 100% similarity to LogoBuilder, and perhaps (let's be humble) with more improvements.

But just the fact of starting the changes, updating the versions, made me see other projects running in parallel. I absolutely cannot be annoyed by that. Quite the opposite, because if users had many more application options to test, that would certainly benefit everyone, since the word **FREEDOM** exists! And I, with absolute certainty, find that incredible.

If we could have more thinking people with time to take advantage of using A.I.s, it would be even more interesting. Although I was the only one who thought about distributing it exclusively for Linux, a user asked if it would be possible to create mtklogo_gui for Windows 10/11. It took a while, but it happened, and maybe soon I'll make the repository open to everyone.
Please, create more forks, make improvements, introduce changes, and do a great job. It will keep me motivated, too.

The project not only evolved in GUI improvements, but also in the correct options and, still at a glance (**Goooooolll**), it gained a multi-image update for `logo.bin` files with A16 (I do not know whether Xiaomi/Redmi/POCO devices and/or `logo.bin` files with A15 can use it and work — tests are needed and feedback is welcome), which can serve as a reference for the other projects. Enjoy it, because it was made to be used simply, easily, and obviously with a pinch of caution/safety.

## What defines mtklogo-gui?

Having small, fully functional main files.

## Is there room for improvement?

**YES!** I myself believe there will always be creative people with willing and great ideas.
